Perfect. I've confirmed the root cause. The container is not running at all, which is why the website doesn't respond.

## Symptom
The website on lab-server does not respond at all.

## Evidence

**docker inspect lab-server** output shows:
- `"Status": "exited"`
- `"Running": false`
- `"ExitCode": 137` (exit code 137 = SIGKILL, process was forcefully killed)
- `"FinishedAt": "2026-11-22T13:54:24.07474222Z"` (exited ~12 minutes ago)
- `"StartedAt": "2026-11-22T13:42:14.279728878Z"` (ran for ~12 minutes)
- `"RestartPolicy": {"Name": "no", "MaximumRetryCount": 0}`

**docker logs --tail 100 lab-server** output: Empty (no logs because main process is just "sleep infinity")

**docker exec lab-server ls /var/www/html** result: `Error: container is not running`

## Root cause
The container exited with exit code 137 (SIGKILL), indicating the process was forcefully terminated (possibly due to OOM or manual kill). With the restart policy set to "no", the container is not automatically restarting, leaving it in a stopped state. Since the container is not running, there is no web server listening for connections.

## Fix
Restart the container:
```bash
docker start lab-server
```

## Verify
Confirm the container is running and responding:
```bash
docker ps | grep lab-server
curl http://localhost:8080
```
